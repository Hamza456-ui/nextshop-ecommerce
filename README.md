# NextShop - Full Stack E-Commerce Website

## 📌 Overview

NextShop is a modern Full Stack E-Commerce web application built with Next.js. It provides customers with an easy shopping experience and an admin panel to manage products.

---

## 🚀 Features

- User Registration & Login
- Product Listing
- Product Details Page
- Shopping Cart
- Checkout Page
- Admin Dashboard
- Add Products
- Edit Products
- Delete Products
- Responsive Design
- MongoDB Database Integration

---

## 🛠 Tech Stack

### Frontend
- Next.js 15
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Next.js API Routes
- Node.js

### Database
- MongoDB
- Mongoose

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/nextshop.git
```

Move into project

```bash
cd nextshop
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## Environment Variables

Create a `.env.local` file

```
MONGODB_URI=your_mongodb_connection_string
```
